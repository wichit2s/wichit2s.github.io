Agentic Views (AV-SQL)

การตอบคำถามภาษาธรรมชาติด้วย SQL บน schema ขนาดใหญ่ทำได้ยาก — AV-SQL แก้ด้วยการสร้าง View แบบโมดูลาร์ที่ Agent สร้างและใช้ซ้ำได้

1. Question Rewriting

แปลคำถามคลุมเครือให้ชัด (เช่น "ลูกค้าที่ใช้งาน" = active_today)

2. View Generation

สร้าง CTE/View ย่อยจาก schema → ลดความซับซ้อนของ Join

3. Iterative Validation

รันตรวจสอบ syntax และผลลัพธ์ แก้จนถูกต้อง

กิจกรรมกลุ่ม (20 นาที)

ออกแบบคำถาม Natural Language ที่ดี

จงออกแบบคำถามภาษาธรรมชาติ 3 ข้อที่ Agent ของคุณตอบได้ และสะท้อนคุณค่าทางธุรกิจ:

1. คำถามที่ถามถึง แนวโน้ม (เช่น "ยอดขายไตรมาส 3 ปีนี้เทียบกับปีที่แล้วเป็นอย่างไร?")
2. คำถามที่เจาะ มิติย่อย (เช่น "สินค้าหมวดไหนขายดีที่สุดในภาคเหนือ?")
3. คำถามที่ต้อง หลาย join (เช่น "ลูกค้าที่ซื้อซ้ำมีกำไรเฉลี่ยเท่าไหร่?")

ตัวอย่าง Demo Questions

แนวโน้ม (Trend)

"ยอดขายปีนี้เทียบกับปีที่แล้วตามเดือนเป็นอย่างไร?"

มิติ (Dimension)

"หมวดสินค้าใดมีกำไรสูงสุดในแต่ละภาค?"

เจาะลึก (Join)

"ลูกค้ากลุ่มซื้อซ้ำ (Repeat Buyers) มีมูลค่าการสั่งซื้อเฉลี่ยเท่าไหร่?"

🎯 เกณฑ์คำถามที่ดี: ต้องเฉพาะเจาะจง วัดผลได้ และสามารถตรวจสอบความถูกต้องของคำตอบได้
