Slide 3 • backend1 — Project Setup

backend1 (Django + Simple JWT): สร้างโปรเจกต์ 🏗️

สร้าง Django project ที่พึ่งพา djangorestframework-simplejwt เพื่อเปิด endpoint ขอ/ตรวจสอบสิทธิ์ — ใช้ uv เหมือนที่เรียนในห้อง (แทน pip + venv) :

# Terminal 1 — จากราก repo สร้างโฟลเดอร์ backend1

$ uv init backend1 && cd backend1

$ uv add django djangorestframework djangorestframework-simplejwt django-cors-headers

$ uv run django-admin startproject config .

# สร้างตารางฐานข้อมูล + บัญชีผู้ใช้สำหรับทดสอบล็อกอิน

$ uv run manage.py migrate

$ uv run manage.py createsuperuser

# สร้าง user ทดสอบ เช่น student01 / test1234

$ uv run manage.py runserver

# → http://localhost:8000

✅ จุดตรวจสอบ Step นี้: หน้า http://localhost:8000 ขึ้น moved permanently / 404 ไม่ใช่ Browser Error = Django รันปกติ ยังเหลือ configure settings กับ urls ในสไลด์ถัดไป

Slide 8 • backend2 — Verify the OP

backend2: ตรวจสอบว่าเป็น OpenID Server ที่ทำงานได้ 🔍

# 1) Discovery document — ต้องเจอ endpoints ครบ

$ http :8000/.well-known/openid-configuration

{"authorization_endpoint": ".../authorize/",

"token_endpoint": ".../token/",

"userinfo_endpoint": ".../userinfo/",

"jwks_uri": ".../jwks/", ...}

# 2) กุญแจ RS256 ที่ใช้เซ็น ID Token

$ http :8000/jwks/

{"keys": [{"kty": "RSA", "alg": "RS256", "n": "...", "e": "AQAB"}]}

เปิดเบราว์เซอร์ไปที่ http://localhost:8000/authorize/?response_type=code&client_id=<id>&redirect_uri=http://localhost:50000 → ถูกพาไปหน้า Login ของ Django = OP ทำงานได้จริง

🔄 Flow ย่อ: หลังทำเสร็จทั้ง 4 โฟลเดอร์

📱 frontend2 (localhost:50000)
① discover → ② GET /authorize/
🔐 backend2 OP (localhost:8000)
③ Login + Consent → redirect ?code=…
🔐 backend2 /token/ + /userinfo/
④ ID Token + Access Token → แสดงชื่อ/อีเมล
✅ ล็อกอินสำเร็จด้วย OIDC

Slide 10 • frontend2 — Flutter + OIDC

frontend2: Flutter พื้นฐานเชื่อม backend2 🪪

# Terminal 2 — แอปต้องรันที่ port ที่ตรงกับ redirect_uris

$ flutter create frontend2 --platforms web

$ cd frontend2

// lib/main.dart — OIDC Authorization Code Flow

final issuer = await Issuer.discover(

Uri.parse('http://localhost:8000'));

final client = Client(issuer, '<client_id จาก Step 7>');

final auth = Authenticator(client,

scopes: ['openid', 'profile', 'email']);

final c = await auth.credential;

if (c == null) auth.authorize(); // ไปหน้า Login

else info = await c.getUserInfo();

🔗 3 จุดที่ต้อง "ตรงกัน" ถ้าเจอปัญหา redirect

  • redirect_uri ที่ลงทะเบียนใน admin backend2
  • port ที่รัน flutter run --web-port 50000
  • ค่าเริ่มต้นของ openid_client (default เป็น localhost:50000 เช่นกัน)
⚠️ อย่าให้ frontend1 กับ frontend2 รัน port ซ้ำกัน: frontend1 ใช้ 40000, frontend2 ใช้ 50000 — เปิดคนละ terminal

Slide 12 • Troubleshooting

แก้ปัญหาที่เจอบ่อยระหว่างทำ 🔧

อาการ สาเหตุ / วิธีแก้ โฟลเดอร์
/api/token/ ตอบ 404 ยังไม่ได้เพิ่ม path ใน config/urls.py ของ backend1 backend1
/api/token/ ตอบ 400/401 user ไม่มีในระบบ หรือ gen token กับ user ที่ถูกต้อง (migrate + createsuperuser ก่อน) backend1
404 /.well-known/... ลืม include('oidc_provider.urls') ใน config/urls.py backend2
No RSAKey in DB / creatersakey ลืม รัน uv run manage.py creatersakey แล้ว restart backend2
redirect_uri_mismatch redirect_uris ใน admin กับ --web-port ของ frontend2 ไม่ตรงเป๊ะ backend2 / frontend2
CORS error ใน DevTools CorsMiddleware ต้องอยู่บนสุดของ MIDDLEWARE + restart runserver backend1/2
เว็บติดต่อ localhost:8000 ไม่ได้ แอปที่รันแบบ web ใช้ localhost ได้โดยตรง — ถ้ารันบนมือถือจริง ต้องให้ server รันบน IP เครื่อง และแก้ URL ในโค้ด frontend1/2
